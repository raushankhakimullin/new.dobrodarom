# Добро Даром — Благотворительный Фонд

Official website of the Добро Даром charitable foundation based in Kazan, Russia.

## Stack
- React 19 + Vite
- Tailwind CSS v4
- Express 5 API server (contact form + donation requests)
- CloudPayments donation widget
- VK + Telegram social feeds
- PostgreSQL + Drizzle ORM

## API Endpoints
- `POST /api/contact` — save contact form messages
- `POST /api/donations` — save donation requests
- `GET /health` — health check
